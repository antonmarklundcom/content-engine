## Decisions
- Markdown is in `.prettierignore`: prompts, plan and logs are hand-wrapped prose, and reflowing
  them would churn every doc for no reader benefit. No ESLint rule disabled.
- `_`-prefixed names are allowed as unused (`no-unused-vars` options), matching the repo's idiom.
- `nav.ts` is pinned by O6's key snapshot test, so new nav strings live in `dict/header.ts`.
