# S5 — One design system

## Built

- `RootLayout` renders `Header` once for the whole app, with `<html lang>` from the locale
  cookie; `/youtube` and `/inbox` layouts no longer render their own header or wrapper.
- `Header`: brand link → `/`, nav gains `Content` → `/` first, nav wraps on phones.
- `TopNav` deleted. `@layer legacy`, every `:not([data-youtube-section] *)` and the
  `data-youtube-section` attribute are gone; `globals.css` is the token system plus a
  base `body` surface/ink rule.
- `/` and `/brand/[id]` ported to `surface-card` / `surface-border` / `--color-*` tokens.
- `BrandIdeas.tsx` is a server component; client islands `BrandIdeaBoard`,
  `BrandGenerateForm`, `BrandIdeaCard` (edit/save, `CopyTextButton` for the caption,
  approve/reject), `SkeletonBlock` while loading, `ResultMessage` for errors (the 403
  text for non-owners comes straight from `/api/generate`). All copy via `dict/brands.ts`
  (en + sv). `posted` status gets a tag.
- `tests/screenshots.mjs`: `/youtube/login` (signed out), `/`, `/brand/propia`, `/inbox`,
  `/youtube` at 390 and 1280; upserts a throwaway owner and signs in via the real form.

## Decisions

- Ideas list is still loaded client-side from `/api/ideas`: no bridge read for ideas
  exists and `src/lib/bridge/ideas.ts` is S6's. S9 moves the list server-side / dedupes
  with S6's `IdeaActions` (not on main when S5 ran).
- `src/app/inbox/layout.tsx` (outside Owns) edited minimally: it rendered a second
  `Header` and carried `data-youtube-section`; the exit grep cannot pass without it.
- Nav label key lives in `dict/brands.ts` (`brands.nav`), since `dict/nav.ts` is not S5's.
- Screenshot sign-in seeds via `pg` + `bcryptjs` inside the script, so `ci.yml` is untouched.

## Known issues

- Exit grep: 3 hits remain, all the word "legacy" in YouTube-API comments
  (`src/lib/youtube/{data-api,url}.ts`, `captions/track.ts`: legacy vanity URLs / caption
  format). Unrelated to CSS, outside Owns; S9 may reword them.
- `Header` has no active-tab highlight (TopNav had one for two tabs); S9 owns the nav.
- S6 merged while S5's PR was open: `IdeaActions`/`IdeaStatusTabs`/`bridge/ideas.ts` are on
  main but not yet mounted on `/brand/[id]` — S9 swaps them in for `BrandIdeaCard`'s buttons.
- The app wordmark is still `app.name` ("YT Intel") though it now links to `/`.
